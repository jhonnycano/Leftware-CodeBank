## Creation of starting point of project:

Locate command line on root of project: `cd {Leftware-CodeBank}`
Execute vite: `npm create vite@latest`

Parameters:
* Project name: todomanager-client-react
* Framework: React
* Variant: TypeScript + SWC


## Installation of NPM packages

The following is the list of npm packages that are used in the project:

```
npm install axios
npm install bootstrap
npm install react-bootstrap
npm install react-router-dom
```

| Package           | Description                                            |
| ===               | ===                                                    |
| Axios             | Allows to send HTTP requests to the server             |
| Bootstrap         | Provides structure and default css styles for the html |
| React-Bootstrap   | Integrates Bootstrap and React                         |
| react-router-dom  | Allows to setup routing in React                       |
